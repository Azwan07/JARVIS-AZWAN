# JARVIS AZWAN v4 Architecture

Input → Context/Memory → Local Command Brain → Permission Boundary → Response/Voice → Audit Log.

Provider layer is intentionally neutral. A future AI endpoint may be configured without changing the UI. No provider credential is bundled.

Device targets represented: iPhone 13 Pro Max gateway, Apple Watch Series 9 quick interface, Ray-Ban Meta Gen 2 vision/voice interface. The latter two are target interfaces, not claimed live integrations in this web build.
